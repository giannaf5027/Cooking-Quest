Cooking Quest is a web app and a game for learning to cook. Target users are middle school through college age. Users pick recipes by difficulty or meal type, follow the steps, and plan a week of meals. The app builds a grocery list from that plan, so shopping is a list, not a memory test. Badges and levels keep it feeling like a game, including the Thyme Turner and Super Sage herb milestones. It recommends recipes based on the ingredients a user already has, and shows birthday recipes around a user's birthday. For fall we ship the front end first: recipes, meal planning, grocery list. Backend and the rest come in later sprints.
